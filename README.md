# Code-Generator by Akshat
Code Generator by Akshat is a web-based application built with Streamlit and powered by Google's Gemini 1.5 Pro model. It allows users to input a problem statement and generate corresponding code in multiple programming languages such as Python, C, C++, and Java.

**🚀 Features**


Accepts natural language problem statements

Generates clean and functional code using generative AI

Supports multiple programming languages

User-friendly interface with custom styling

🧠 Powered By 

Streamlit

Google Generative AI
